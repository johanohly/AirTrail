**Deprecated:** This endpoint will be removed in the next major AirTrail release. Migrate to `POST /api/v1/flights` for new flights or `PUT /api/v1/flights/{id}` for updates. Create a new flight or update an existing one. Creating a flight for the API-key user requires `flight.create.own`; creating one for other users requires `flight.create.any`. Updating follows the equivalent `flight.update.*` permissions. On an existing flight, adding, removing, or changing passengers requires the matching `flight.passengers.manage.*` permission.
