AirTrail runs as two containers: the app and a PostgreSQL database. Most people run it with Docker Compose on a Linux server, NAS or Raspberry Pi. Check the [requirements](/docs/install/requirements) first.

## The short version

On a machine with Docker and Docker Compose v2:

```bash
mkdir airtrail && cd airtrail
wget -O docker-compose.yml https://raw.githubusercontent.com/JohanOhly/AirTrail/main/docker/production/compose.yml
wget -O .env https://raw.githubusercontent.com/JohanOhly/AirTrail/main/.env.example
```

Edit `.env`: set `ORIGIN` to the URL you will open AirTrail at, and change `DB_PASSWORD` together with the password inside `DB_URL`. Then start it:

```bash
docker compose up -d
```

Open the URL from `ORIGIN` and follow the [post-installation](/docs/install/post-installation) steps. The [Docker Compose guide](/docs/install/docker-compose) explains each step in detail.

## Before you open it to the internet

- Put AirTrail behind a [reverse proxy](/docs/install/reverse-proxy) with HTTPS.
- Set up [backups](/docs/administration/backup) of the database and uploads.
