Get insights into your flying habits with the statistics page.
Statistics are available through the bottom navigation bar.

<Screenshot name="statistics" alt="The statistics page with totals, charts and a breakdown by seat and class" />

## Fields

<Callout>
  By default, statistics only take into account flights that have been
  completed. When the current filters include upcoming flights, a switch above
  the statistics adds them, and its label says how many there are. AirTrail
  remembers the choice in your browser.
</Callout>

| Field              | Description                                                                |
| ------------------ | -------------------------------------------------------------------------- |
| Flights            | The total number of flights.                                               |
| Distance           | The total distance of the flights.                                         |
| Duration           | The total time in the air.                                                 |
| Airports           | The total number of airports the flights use.                              |
| Seat Classes       | The distribution of flights by seat class (Economy, Business, etc.).       |
| Seat Distribution  | The distribution of flights by seat (Window, Aisle, etc.).                 |
| Flight Reason      | The distribution of passenger records by reason (Business, Leisure, etc.). |
| Continents Visited | The amount you have visited each continent.                                |
| Flights by month   | The amount of flights per month.                                           |
| Flights by weekday | The amount of flights per weekday.                                         |
