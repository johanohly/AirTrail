---
title: Aircraft Photos
---

Aircraft photos are shown next to a flight's details when it has a registration and the integration is enabled.

## How It Works

AirTrail looks up the aircraft's photo by its registration on [Planespotters.net](https://www.planespotters.net/photo/api):

- **No API key needed**: the Planespotters photo API is free and keyless.
- **One photo per airframe**: the public API returns the airframe's latest photo. AirTrail pins the photo to a flight when it is first fetched, so the photo stays stable even if the aircraft is repainted or the photo is later removed on Planespotters.
- **Refreshed on demand**: changing a flight's registration in the flight form fetches a new photo, and the photo card in the flight details has a refetch button.
- **Attribution**: photos are always credited to their photographer, with a link to the photo page on Planespotters.net. Keep this attribution intact.

## Setup

- In the app (admins only): Settings → Integrations → "Aircraft Photos".
- Or via environment variable: set `INTEGRATIONS_AIRCRAFT_PHOTOS_ENABLED=true` and restart the server.

## Privacy Notes

- When the feature is enabled, AirTrail sends the aircraft registration of flights you view to Planespotters to look up photos.
- Photos are fetched by your browser directly from Planespotters' image servers — AirTrail never proxies or stores the images themselves, only the metadata needed to display and credit them.
- Photo lookups are only performed for signed-in users of your instance; nothing is exposed publicly.
